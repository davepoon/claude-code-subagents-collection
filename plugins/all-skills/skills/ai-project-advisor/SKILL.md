# 工程项目 AI 顾问（AI Project Advisor）

面向中小装修/施工/工程公司（5-50 人）的**对话式工程管理顾问**：老板正常发消息/发文件/发语音 → AI 记录、汇总、诊断、预警。不改变使用习惯，不用学新系统。

## 产品定位

**AI 顾问 = 记录一切、盯住风险、给出专业建议——让老板不用天天盯项目。**

| 三必做（锚） | 说明 |
|:---|:---|
| ✅ **记录** | 对话即档案（说了就记，原话+时间+人） |
| ✅ **盯** | 节点/回款/风险——异常主动预警 |
| ✅ **建议** | 专业顾问——给方法，不只是报问题 |

| 三不做（红线） | 说明 |
|:---|:---|
| ❌ OA | 审批流/人事/考勤/报销 |
| ❌ 商业决策 | 比价/选型/替客户拍板——只记录事实、提醒风险 |
| ❌ 大而全 ERP | 进销存/财务全模块 |

## 核心设计一：对话即档案（记忆图谱）

每个项目一个记忆图谱：**人（公司内部+甲方+关联方）+ 说过的话 + 做过的事 + 承诺**——时间+原话存档。

- **清款依据**："甲方答应 7 月付尾款" → 调出原话+时间
- **防赖账**：增项不认 → 调确认记录
- **内部防扯皮**："你当时说材料下周到"
- **换人交接、经验沉淀**：人走了记录不丢

## 核心设计二：说话录数据（把填表变说话）

老板不愿填表但愿意发微信——**AI 从对话自动提取结构化**（"B项目收了进度款20万"→自动更新台账）。

- **A 级（主力）**：对话自动记录（收款/变更/承诺/问题/进度）
- **B 级（存量）**：上传 Excel/台账 → AI 解析导入（自动识别项目名称/金额/工期/节点）
- **C 级（后期）**：对接财务/进销存自动同步

## 核心设计三：数据投喂闭环

**客户只投喂基础资料（一次性 10 分钟引导式建档），动态数据 AI 自己维护**——解决"老板不主动录数据、系统空转"的冷启动难题。

- 引导式建档 6 步：合同/图纸/工期/付款节点/供应商/负责人——AI 一步步引导，答一步确认一步
- 顾问主动要求资料（像真人顾问"把合同给我"），不是等客户自己给
- 动态数据三通道：① AI 每日主动问（"今天有什么进展？回款有消息吗？"）② 拍照/语音/聊天自动记录 ③ 公开数据自动扫描

### 节点时间三档原则（AI 不替客户规划）

1. **文件/合同里有节点** → LLM 自动提取标注（按文件建节点，标注"依据文件"）
2. **客户口头提供节点** → 录入，标注"客户提供"
3. **无节点信息** → 提醒客户提供，不自行推算

## 核心设计四：意图识别 + 事件落库

消息进来先做意图分类（关键词规则 + LLM 增强），业务事实自动写入项目档案：

| 你说的话 | 意图 | AI 会做什么 |
|:---|:---|:---|
| "提前进度2天完成了" | progress | 存入项目档案，回复"进度已记录" |
| "甲方给我打电话说马上要回款" | payment | 记录回款事件；有金额则自动更新累计收款；无金额记"承诺回款"+到期提醒 |
| "先干着，后面再说" | change | 记录变更并**强提醒补签证**（口头变更=结算扯皮头号原因）|
| 其他 | record | 默认记录（原文+摘要）|

## 核心设计五：知识库三层

- **内置行业知识**（SEED_KB）：质保金比例、签证规范、工期常识等常用规则
- **项目档案**（events/里程碑/文档）：项目专属事实
- **外部知识注入**：客户问题相关时引用并注明出处

## 部署架构（参考）

- 消息通道：企业微信自建应用回调（文本/图片/语音）
- 服务器：任意 Linux 云主机（Python 3.10+，SQLite）
- LLM：任意 OpenAI 兼容接口
- 多租户：每客户独立数据库文件 + 群↔项目绑定

## 已实现功能清单

- ✅ 引导式建档（合同/图纸/工期/付款节点/供应商/负责人）
- ✅ 对话自动记录（收款/变更/承诺/问题/进度，原文+摘要留档）
- ✅ 8 大顾问模块（进度/回款/变更/风险/巡检/新人等）
- ✅ 节点时间三档原则（不替客户规划）
- ✅ 风险预警（安全事故升级处理/口头变更强提醒/回款逾期提醒）
- ✅ 每日群聊汇总日报（进展/问题/承诺/变更 → 文件+推送）
- ✅ 项目复盘材料自动生成
- ✅ 文件解析（Excel 报价单/清单 → 自动建项目，金额/工期/节点提取）
- ✅ 多群隔离 + 群↔项目绑定

## 使用场景

- 工程公司老板在项目群里发消息 → AI 记录并回复
- "B项目收了进度款20万" → 自动更新台账 + 回复确认
- "甲方说马上回款" → 记录承诺 + 到期提醒
- "先干着后面再说" → 强提醒补签证
- 每日 22:00 自动生成项目日报发群
